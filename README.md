# Projeto ACEX — Integração da Reciclagem às Atividades Complementares

## Sobre o Projeto

Aplicação voltada aos estudantes da Fundação Santo André com o objetivo de incentivar práticas sustentáveis através da conversão de materiais recicláveis em horas complementares.

---

## Objetivos

- Incentivar a reciclagem;
- Facilitar localização de pontos de coleta;
- Registrar entregas recicláveis;
- Converter reciclagem em horas complementares;
- Promover educação ambiental.
